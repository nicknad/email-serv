# Email-Serv

This is a lightweight Rust-based backend service for managing mailing lists. It provides a way for users to **subscribe** and **unsubscribe** as well wil it **send emails** to a list of subscribers. The project’s main purpose is to explore **Rust**—from architecture and error handling to concurrency, testing, and deployment. 

## 🧪 Running Locally
git clone https://github.com/nicknad/email-serv \
cd email-serv \
cargo run or cargo test
